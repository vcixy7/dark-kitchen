# Flash Food - Tela de Login

Este é o meu projeto proprietário desenvolvido em Angular. Abaixo estão as instruções diretas para você baixar, rodar e testar este código localmente na sua máquina.

## Pré-requisitos
Certifique-se de ter o **Node.js** instalado no seu computador para conseguir rodar projetos em Angular.

## Como rodar o projeto na sua máquina

Siga os passos abaixo no seu terminal:

**1. Faça o clone do repositório:**
```bash
https://github.com/vcixy7/dark-kitchen.git
```

**2. Entre na pasta do projeto:**
```bash
cd dark-kitchen
```

**3. Instale as dependências do projeto:**
```bash
npm install
```

**4. Inicie o servidor local:**
```bash
ng serve
```
*(Caso não tenha o Angular CLI instalado globalmente, você pode rodar `npm start`)*

**5. Acesse no navegador:**
Abra o seu navegador de preferência e digite o endereço:
`http://localhost:4200`
